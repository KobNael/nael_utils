Exception

Defines

MAKE_EXCEPTION(class_name)

Create a new type of exception.

Example: 

namespace test
{
    MAKE_EXCEPTION(base)
    void throw_base()
    {
        throw test::base("dedicated error");
    }
}

Parameters:

  • class_name – the name of the class

CHECK_PRE(cond, message)

Throw a fatal error if the condition is not verified.

Parameters:

  • cond – the condition to verify

  • message – the error message to throw in case of failure
