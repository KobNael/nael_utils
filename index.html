Utils documentation

This library regroup some usefull tools for c++ applications :

  • Log utilities : Utils for logging

  • Exception : Tool for dedicated exception

  • Data Model Utils: Utils for data model description

  • Json utilities: Utils for json import/export

  • String utilities: Utils for string manipulation

  • Safe numerical comparison : Utils for safe numeric comparison

  • Basic computation : Utils for basic computation

  • Lexical sort : Interface for lexical sort with tolerance

  • Sorted List Utilities : Utils for sorted list manipulation

  • Period utilities: Utils for period (with capacity) manipulation

  • Thread Pool : Tool for parallel computation
